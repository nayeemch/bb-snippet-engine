Features

Everything you need to extend BuddyBoss

From a frosted-glass admin UI to GitHub Gist sync and safe PHP validation — BBSE handles the heavy lifting.

🧩

Card-based block management

Create, edit, delete, and toggle blocks from a clean paginated grid. Each block is independent — switch one off without affecting the others.

🛡️

Safe PHP validation

PHP is validated with token_get_all() and TOKEN_PARSE — syntax-only, no execution. A broken snippet can never cause a white screen.

✨

Smart Unicode normalization

Code copied from web pages often contains invisible characters that break PHP and JS. BBSE strips them automatically on every save.

🔄

GitHub Gist remote sync

Point BBSE at a GitHub Gist and click Sync. New blocks are created, existing blocks are updated, and removed blocks are deactivated — locally-created blocks are never touched.

🔍

Live search & smart sort

Filter cards as you type with a clear button. Sort by Active first, Inactive first, Name A–Z, Name Z–A, or By type. Pagination stays in sync.

✏️

CodeMirror editors

Every block has three syntax-highlighted editors — one each for CSS, JS, and PHP — all on separate tabs inside a modal. Edit without leaving the page.

CSS

Injected as a <style> tag in <head> via wp_head

JavaScript

Injected as a <script> tag in the footer via wp_footer

PHP

Executed server-side via wp_head at early priority

How it works

Up and running in minutes

No configuration wizard, no builder. Drop the plugin in, activate, and start adding snippets.

Install & activate

Drop the bb-snippet-engine folder into wp-content/plugins/ and activate from the WordPress Plugins screen.

Open the panel

Navigate to BuddyBoss → BBSE in your WordPress admin. The plugin creates its database table automatically on first run.

Create a block

Click Add New Block, name your snippet, paste CSS, JS, or PHP into the editor tabs, and save.

Toggle it on

Flip the switch on the card. Active blocks are injected into every front-end page load instantly — no cache flush required.
